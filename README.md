# Instaladores oficiais do LouvaShow

Repositório público exclusivo de distribuição. O código-fonte é mantido em repositório privado.

- [macOS 14 ou superior — DMG universal Intel e Apple Silicon](https://github.com/dantetesta/louvashow-updates/releases/latest/download/LouvaShow-macos-universal.dmg)
- [Windows 10 e 11 — instalador x64](https://github.com/dantetesta/louvashow-updates/releases/latest/download/LouvaShow-windows-x64-setup.exe)
- [Versões e novidades](https://github.com/dantetesta/louvashow-updates/releases)

O aplicativo macOS é assinado e notarizado pela Apple. O instalador Windows não possui assinatura Authenticode; ambos os pacotes de atualização são assinados para verificação pelo LouvaShow. Instalações até 0.7.7 precisam instalar manualmente um pacote atual uma vez para migrar a chave do atualizador.
